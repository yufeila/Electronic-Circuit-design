## 设计原理

1. 方波：通过定时器产生固定频率的中断，在中断服务函数中改变 DAC 输出的值，从而实现方波的输出。
	1. 例如，当定时器中断发生时，将 DAC 输出值设置为最大值，持续一段时间后，再将其设置为最小值，如此反复，即可得到方波信号。
	2. 信号频率1kHz, 定时器频率是2kHz
	3. 我们找一组因子为 36,000 的参数，举例：

|Prescaler (PSC)|ARR (Auto Reload)|
|---|---|
|**359**（→360）|**99**（→100） ✔️|
|179|199|
|71|499|

推荐使用：**PSC = 359，ARR = 99**，这样计数器从 0 数到 99，每 0.5ms 产生一次更新事件。

2. 三角波：同样利用定时器中断，在中断服务函数中按照一定规律改变DAC 输出值。先逐渐增加 DAC 输出值，直到达到最大值，然后再逐渐减小，直到达到最小值，如此循环，便可产生三角波。 

	- 采样频率 64kHz
	- 计算 : $\frac{m}{64} = n$ 
		- $m = 0$, $n = 0$,$v_{o} = 0 \times 3.3V = 0$
		- m = 31, n = 255, $v_{o} = 3.3V$
		- m = 63, n = 0, $v_{o}=0V$
	- 表格
			将 n 初始化为一个不为0 的值

| m 值 | tri_table[n] |
| --- | ------------ |
| 0   | 0            |
| 31  | 255          |
| 32  | 255          |
| 63  | 0            |


3. 正弦波：预先在内存中存储一个正弦波的查找表，表中存放不同相位对应的正弦值。通过定时器中断，按照一定的频率从查找表中读取数据，并通过 DAC 输出，从而得到正弦波信号。
	1. 可以将查找表存放在内存中，利用DMA搬运数据到外设。


$$

$$
在一个周期内采样64个点。

### 原理图设计

1. STM32 最小系统：包括晶振电路、复位电路、电源电路等。晶振电路采用8MHz 的外部晶振，为 STM32 提供时钟信号。复位电路采用按键复位方式，确保系统能够可靠复位。
2. **晶振电路** :STM32有外部晶振和内部的RC晶振（外部晶振更加稳定），使用SystemInit()函数配置，先调用内部8MhzRC振荡器，再将外部晶振经过PLL锁相环倍频到72MHz，等到稳定之后，作为系统时钟。如果**外部时钟出问题**，系统就无法切换到外部时钟，只能用8MHz RC时钟。
3. **复位电路:** 
4. DAC 输出电路：将 STM32 的 DAC 输出引脚连接到低通滤波电路，经过滤波后输出模拟信号。 
5. 电源电路：USB 接口接入 5V 电源，经过 LM1117 稳压芯片后输出3.3V 电源，为整个系统供电。


## 软件设计

### 程序结构

我们的程序按照如下结构展开：

```
+----------------------------+
|       应用层（App）       | ← 用户逻辑（比如按键控制LED）
+----------------------------+
|     驱动接口层（Driver）  | ← 按键、串口、定时器等模块驱动封装
+----------------------------+
|   板级支持包（BSP）       | ← 适配MCU硬件的初始化代码（GPIO、UART Init等）
+----------------------------+
|        HAL库或裸机        | ← STM32 HAL库 / LL库 / 寄存器操作
+----------------------------+
|        硬件平台           |
+----------------------------+

```

文件夹结构

```
/Core
    ├── /App                    # 应用层代码（业务逻辑）
    │     └── main_logic.c
    │     └── main_logic.h
    ├── /Drivers                # 驱动层（模块封装）
    │     ├── key.c / key.h         ← 按键模块
    │     ├── timer.c / timer.h     ← 定时器模块
    │     └── uart.c / uart.h       ← 串口模块
    ├── /BSP                    # 板级支持包
    │     └── bsp_gpio.c / .h      ← GPIO初始化封装
    │     └── bsp_uart.c / .h      ← 串口初始化
    │     └── bsp_timer.c / .h     ← 定时器初始化
    ├── main.c                  # 程序入口
    └── ...

```


1. Drivers：
	1. 定时器模块：主要是中断服务函数，定时器1（控制正弦波与三角波）中断内实现输出移位功能；定时器2(控制方波)中断内实现输出方波的GPIO电平翻转功能。
	2. 按键模块：主要是获取按键的值
	3. 串口模块：待补全
2. main: 
	1. 一些默认配置，在main中做好。
	2. 在循环中(调用main_logic)：
		1. 反复获取按键的值
			1. 当key = 1时，启动定时器1，关闭定时器2，输出方波
			2. 当key = 2时，启动定时器2，关闭定时器1，初始化`cnt = 0, state = 0`, 当`cnt`随着定时中断函数而增加，达到256时，翻转`state`,并将`cnt`置零。 
			3. 当key = 3时，启动定时器2，关闭定时器1.输出正弦波
