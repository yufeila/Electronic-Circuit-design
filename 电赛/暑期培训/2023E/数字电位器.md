X9C102、X9C103、X9C104、X9C503 是 Intersil 公司生产的数字可控（XDCP）电位器。这类器件由**电阻阵列**、**滑动开关**、**控制单元**和**非易失性存储器**组成。滑动端（wiper）的位置由**三线接口**控制。

**电位器**由一个包含**99个电阻元件的电阻阵列**和一个**滑动开关网络**实现。在每个电阻元件之间以及两端，都有可通过滑动端访问的抽头点。滑动端的位置由**CS、U/D和INC引脚控制**。滑动端的位置可以存储在**非易失性存储器**中，并在**下次上电时恢复**。

该器件既可作为**三端电位器**，也可作为**二端可变电阻**，广泛应用于控制、信号处理、参数调整等各种场合。


| 引脚号 | 引脚名     | 描述                                                                                   |
| --- | ------- | ------------------------------------------------------------------------------------ |
| 1   | INC     | **递增/递减**（INCREMENT）：INC输入为**下降沿触发**。INC引脚翻转时，会根据U/D引脚的逻辑电平，推动滑动端向上或向下移动一个位置。        |
| 2   | U/ D̅   | **上下控制**（UP/DOWN）：U/D输入控制滑动端的移动方向，以及计数器是递增还是递减。                                      |
| 3   | V_H/R_H | **高端（V_H/R_H）**：等效于机械电位器的固定端。最小电压为-5V，最大为+5V。这里的V_H/R_H和V_L/R_L用来表示相对位置，而不是实际的端子电位。  |
| 4   | V_SS    | **V_SS**：电源地                                                                         |
| 5   | V_W/R_W | **滑动端（V_W/R_W）**：等效于机械电位器的可变端。其位置由控制输入决定。滑动端典型串联电阻为40Ω。                              |
| 6   | R_L/V_L | **低端（R_L/V_L）**：等效于机械电位器的固定端。最小电压为-5V，最大为+5V。用来描述相对位置而非端子实际电位。                       |
| 7   | CS      | **片选（CS）**：当CS为低电平时，设备被选中。当前计数值会在CS拉高且INC也为高时，存入非易失性存储器。在存储操作完成后，器件会进入低功耗待机，直到下次被选中。 |
| 8   | V_CC    | **V_CC**：电源正极                                                                        |


## 使用说明与编程

![[Pasted image 20250711141057.png]]





INC、U/D 和 CS 输入用来控制滑动端在电阻阵列上的移动。将 **CS 置为低电平**时，器件被选中，能够响应 U/D 和 INC 输入。INC 从高到低的跳变会使 7 位计数器递增或递减（具体方向由 U/D 输入的电平决定）。该计数器的输出会被译码，选择电阻阵列上一百个滑动端位置中的一个。

只要在 INC 也为高电平的情况下，CS 从低变高，计数器的数值就会被存储到非易失性存储器中。

系统可以**选中 X9Cxxx**，移动滑动端，然后取消选中，无需将最新滑动端位置写入非易失性存储器。当滑动端调整到位后，系统必须保持 INC 为低电平，同时拉高 CS。此时，新设置的滑动端位置会一直保持，直到系统再次修改，或掉电重启后恢复上次存储的数据。

这种操作方式使系统能够在每次上电时，自动恢复到存储在非易失性存储器中的预设值；在系统运行过程中，也可根据需要进行微调。例如，可以根据用户偏好、系统参数变化或温漂等情况进行调整。

在 CS 维持低电平时，U/D 的状态可以随时改变。这允许主控系统在设备使能后，灵活地控制滑动端上下调整，直到获得所需的精确修正值。
