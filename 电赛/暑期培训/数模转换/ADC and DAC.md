## 扫描模式和独立模式
### 2019

需要采样多个通道：采用扫描模式

  
### 2020

只需采样一个通道，只需要采用独立模式

需要将采集到的信号存放在4个不同的数组中，每个数组都需要做FFT,


## 扫描模式

```
hadc1.Init.ScanConvMode = ENABLE;
```

ENABLE：开启扫描模式，ADC会按照设定的“通道序列”依次采样。

DISABLE：关闭扫描模式，ADC只采集当前通道（单通道模式）。



## 连续模式

连续模式下，ADC在**一次启动后会自动不断进行新一轮转换**

```
hadc1.Init.DMAContinuousRequests = ENABLE;   // 或 DISABLE
```

**A. ENABLE（持续请求）**

- 用于**连续采样、循环采集**。
    
- 只要 ADC 工作，DMA 会一直搬运数据（比如环形缓冲区、音频流/信号连续分析）。
    
- 多配合**循环模式DMA（DMA_CIRCULAR）**使用，实现不断填充数据流。
    

**B. DISABLE（非持续请求）**

- 适合**只需要采集一批数据**，例如“只需要一次性采集100个点”。
    
- 采集一组后，DMA停止搬运，必须手动重新启动。

## 采样周期公式计算

![[Pasted image 20250703141725.png]]

转换时间: $T_{conv}$
设采样时间为: $T_{sample}$ : $T_{sample} = mT_{clk}$

$$
T_{conv} = (m+12.5) T_{clk}
$$

转换频率(对于FFT，这也是采样频率)
$$
f_{s} = \frac{1}{T_{conv}} = \frac{1}{m+12.5}f_{clk}
$$
$$T_{clk} = \frac{HCLK}{Prescaler}$$
9MHz/(71.5+12.5) = 107,143


## 独立多通道采样

ADC 的工作参数具体如下:
1. 打开 ADC 外设时钟;因为**只是使用一个 ADC**,所有模式配置为**独立模式**;
2. 多通道采集,开启**扫描模式**;
3. 需要不断的采集外部的模拟数据,所有使能**连续转换模式**;
4. **不使用外部触发**转换信号(DISABLE);
5. 转换结果**右对齐**;
6. 设置**需要转换的通道的个数**,最后调用 ADC_Init() 函数把这些参数写入 ADC 的寄存器完成配置。
7. 因为是多通道采集,所以调用 ADC_RegularChannelConfig()  函数设置**每个通道的转换顺序**和采样实际
