
## stm32的地址映射
![[Pasted image 20250629093012.png]]

在stm32f03_xe.h中

定义了STM32 片上和片外存储、外设等主要空间的基地址

```
#define FLASH_BASE            0x08000000UL /*!< FLASH base address in the alias region */

#define FLASH_BANK1_END       0x0807FFFFUL /*!< FLASH END address of bank1 */

#define SRAM_BASE             0x20000000UL /*!< SRAM base address in the alias region */

#define PERIPH_BASE           0x40000000UL /*!< Peripheral base address in the alias region */

  

#define SRAM_BB_BASE          0x22000000UL /*!< SRAM base address in the bit-band region */

#define PERIPH_BB_BASE        0x42000000UL /*!< Peripheral base address in the bit-band region */

  

#define FSMC_BASE             0x60000000UL /*!< FSMC base address */

#define FSMC_R_BASE           0xA0000000UL /*!< FSMC registers base address */
```

这几行代码定义的是**STM32 片上和片外存储、外设等主要空间的基地址**，是所有 STM32 芯片**内存和外设寻址的基础**。  
这些定义通常出现在 `stm32f1xx.h`（或其它系列芯片的头文件）中，被整个 HAL 库和用户代码反复引用。

### 1. FLASH_BASE & FLASH_BANK1_END

```c
#define FLASH_BASE       0x08000000UL  /*!< FLASH base address in the alias region */
#define FLASH_BANK1_END  0x0807FFFFUL  /*!< FLASH END address of bank1 */
```

- **FLASH_BASE**：片上Flash存储区的起始地址（一般为主程序存储区，比如STM32F1最大512KB对应0x0800 0000~0x0807 FFFF）。
    
- **FLASH_BANK1_END**：片上Flash第1区（bank1）的结束地址。
    

---

### 2. SRAM_BASE

```c
#define SRAM_BASE        0x20000000UL  /*!< SRAM base address in the alias region */
```

- **SRAM_BASE**：片上SRAM（静态随机存取存储器）基地址。程序运行中的全局变量、栈、堆空间等都分配在这块区域。
    

---

### 3. PERIPH_BASE

```c
#define PERIPH_BASE      0x40000000UL  /*!< Peripheral base address in the alias region */
```

- **PERIPH_BASE**：片上外设（如GPIO、USART、ADC、TIM、I2C等控制寄存器）映射到总线上的基地址。
    

---

### 4. Bit-band区相关

```c
#define SRAM_BB_BASE     0x22000000UL  /*!< SRAM base address in the bit-band region */
#define PERIPH_BB_BASE   0x42000000UL  /*!< Peripheral base address in the bit-band region */
```

- **SRAM_BB_BASE** 和 **PERIPH_BB_BASE**：**位带（bit-band）区**基地址。
    
    - 允许你用特殊的寻址方式直接对SRAM和外设的单个位进行原子操作，非常适合做IO口操作、信号标志位等场景。
        
    - 比如写 `*(volatile uint32_t *)(PERIPH_BB_BASE + (GPIOx_ODR_offset * 32 + bit_number * 4))` 可以直接设置某个外设寄存器的单个位。
        

---

### 5. FSMC相关

```c
#define FSMC_BASE        0x60000000UL  /*!< FSMC base address */
#define FSMC_R_BASE      0xA0000000UL  /*!< FSMC registers base address */
```

- **FSMC_BASE**：外部总线接口FSMC（Flexible Static Memory Controller）的存储区基地址，即你挂在FSMC上的外部SRAM、LCD、PSRAM、NOR Flash等的首地址（比如上面说的0x6000 0000）。
    
- **FSMC_R_BASE**：FSMC控制器寄存器组的基地址，只有访问这个地址区的寄存器才能配置FSMC的各种参数和状态。

## 关于像素

###  显示屏（LCD、OLED等）中的“像素”

- **一个像素（pixel）**就是屏幕上**最小的独立显示单元**，通常可以显示不同的颜色。
    
- 在LCD、OLED、TFT等显示屏中，每个像素由若干个子像素（红、绿、蓝）组成，可以通过混合显示出各种颜色。
    
- **在代码层面上，显示驱动给每个像素分配一个坐标（如X、Y）和颜色数据。**
    

---

###  LED矩阵中的“像素”

- 如果你指的是**点阵LED显示屏**（LED Matrix、LED大屏），**一个像素通常就是一个LED灯点**，每个LED可以单独亮灭，部分高端LED屏（如RGB全彩）一个“像素”是由一个红、绿、蓝LED组成的发光单元。
    
- 在更大的户外LED屏（“灯珠屏”），**一个像素就对应一颗独立的LED模块**，可以是单色，也可以是RGB组合。

## 踩坑记录

1. CubeMX 中的Memory Type只有LCD Interface, 它默认采用SRAM, 而例程使用的是 NOR FLASH , 其实我们可以用SRAM来驱动LCD显示屏，并且我们并不需要将显示屏初始化
2. 我们需要在CubeMx中手动配置LCD_BK(背光引脚)和LCD_RST, 都配置成推挽输出，Pull up , 速度设置为高
3. 数据延时可能得设置的快一些。
