
## GPIO外设

| 寄存器               | 作用（每个端口一组）        |
| ----------------- | ----------------- |
| `GPIOx->MODER`    | 端口模式（输入/输出/复用/模拟） |
| `GPIOx->OTYPER`   | 输出类型（推挽/开漏）       |
| `GPIOx->OSPEEDR`  | 输出速度              |
| `GPIOx->PUPDR`    | 上拉/下拉配置           |
| `GPIOx->IDR`      | 输入数据（读当前引脚状态）     |
| `GPIOx->ODR`      | 输出数据（写/读当前输出电平）   |
| `GPIOx->AFR[0/1]` | 复用功能选择（AF0~AF15）  |
|                   |                   |

### mode 

**观察以下内容：**

- **MODER**：每2位一个引脚，00=输入，01=输出，10=复用，11=模拟
    
- **OTYPER**：0=推挽，1=开漏
    
- **PUPDR**：每2位一个引脚，00=无，01=上拉，10=下拉
    
- **IDR/ODR**：实际电平（IDR是输入状态，ODR是软件输出的数据）
    
- **AFR[0/1]**：复用功能选择（外设映射）

## 外设时钟


- `RCC->AHB1ENR` (F4/F7系列，确定端口时钟使能)
    
- `RCC->APB2ENR`/`RCC->APB1ENR` (F1系列)
